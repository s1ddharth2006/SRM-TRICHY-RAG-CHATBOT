🚀 Universal Integration Guide

Integrate this chatbot on the main website (https://www.srmtrichy.edu.in), subdomains, or any CMS (WordPress, React, HTML, Next.js). The widget auto-detects its API host, auto-injects required styles, and operates fully with zero external dependencies.

Add this single line right before the closing </body> tag of any page:

HTML </body> Embed 
<!-- SRM IST Trichy AI Chatbot Embed (Standalone) -->
<script src="https://your-chatbot-server.com/embed.js" defer></script>

<!-- OR for Chatbot + Full Site Bilingual Translation -->
<script src="https://your-chatbot-server.com/srm-tamil-widget.js" defer></script>

Note: If running locally for testing, replace with http://localhost:3000/embed.js.

If the script is hosted on a CDN or different domain than the backend API:

Explicit Backend API Host 
<script>
  window.SRM_CHAT_API_URL = "https://api-chatbot.srmtrichy.edu.in";
</script>
<script src="https://cdn.srmtrichy.edu.in/srm-tamil-widget.js"></script>

In Next.js (App or Pages Router) or Vite React application:

Next.js / React Component 
// app/layout.tsx or pages/_app.tsx
import Script from 'next/script';

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>
        {children}
        <Script 
          src="https://your-chatbot-server.com/srm-tamil-widget.js" 
          strategy="lazyOnload" 
        />
      </body>
    </html>
  );
}

For WordPress administrators:

  1. Install the "Insert Headers and Footers" (WPCode) plugin or go to Appearance → Theme File Editor → footer.php.
  2. Paste the embed code into the "Scripts in Footer" field:
WordPress Footer Code 
<script src="https://your-chatbot-server.com/srm-tamil-widget.js" defer></script>
