🚀 Integration by Platform

Choose your website stack below to see the quick copy-paste instructions:

Paste this 1-line script right before the closing </body> tag on any HTML or PHP template:

<!-- Place right before </body> in your index.html or footer.php -->
<script src="https://your-chatbot-server.com/embed.js" data-api="https://your-chatbot-server.com" defer></script>

In your WordPress Admin Dashboard, choose either method:

  1. Go to Appearance → Theme File Editor → footer.php.
  2. Paste the script tag directly above <?php wp_footer(); ?>.
  3. Or use a plugin like "WPCode - Insert Headers and Footers" and add the snippet into the Footer Scripts section.
<script src="https://your-chatbot-server.com/embed.js" data-api="https://your-chatbot-server.com" defer></script>

In Next.js (App Router or Pages Router), add via next/script in your root layout:

import Script from 'next/script';

export default function RootLayout({ children }) {
  return (
    <html lang="ta">
      <body>
        {children}
        <Script 
          src="https://your-chatbot-server.com/embed.js" 
          data-api="https://your-chatbot-server.com"
          strategy="lazyOnload" 
        />
      </body>
    </html>
  );
}

In Webflow Project Settings:

  1. Go to Project Settings → Custom Code.
  2. Paste into the Footer Code box (Before </body> tag).
  3. Click Save & Publish.
